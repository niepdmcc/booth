# بوابة المعهد الوطني للتطوير المهني التعليمي

صفحة تفاعلية لبوث المعهد. تتكون من صفحة رئيسية فيها بطاقات الأقسام، وصفحات الأقسام، والفيديوهات.

## محتويات المجلد

| المسار | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `pages/` | صفحات الماجستير المهني، وملهم، والتحول الإستراتيجي |
| `media/` | فيديو ملهم وفيديو نمو |
| `img/` | البطاقات والخلفيات والشعار |

## الرفع على GitHub Pages

1. أنشئي مستودعاً جديداً على GitHub، وخليه عاماً (Public).
2. ارفعي كل محتويات هذا المجلد كما هي إلى جذر المستودع، مع الحفاظ على المجلدات.
3. من **Settings ← Pages** اختاري:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **المجلد:** `/ (root)`
4. اضغطي **Save**.
5. بعد دقيقة أو دقيقتين يطلع لك الرابط بهذا الشكل:
   `https://اسم-الحساب.github.io/اسم-المستودع/`

## بدائل أسهل

- **Netlify Drop** على الرابط app.netlify.com/drop: اسحبي المجلد كاملاً إلى الصفحة ويطلع لك رابط مباشرة.
- **Cloudflare Pages** أو **Vercel**: كذلك ترفعين المجلد كما هو.

## ملاحظات

- الصفحة لازم تنفتح من رابط على الإنترنت أو من خادم محلي. إذا فتحتِ ملف `index.html` بالضغط عليه مباشرة من الجهاز، ما تفتح صفحات الأقسام، وما تطلع اللمعة حول البطاقات.
- أكبر ملف هو فيديو ملهم، وحجمه حوالي 8 ميجا. هذا ضمن حدود GitHub، لأنه يقبل الملف حتى 100 ميجا.
- لتعديل الإعدادات افتحي `index.html` وابحثي عن `CARDS` و `AUTO_EVERY` و `PAGE_IDLE`. منها تتحكمين في البطاقات، وسرعة التنقل التلقائي، ومدة الرجوع للرئيسية.
